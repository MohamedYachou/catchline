## Processing and technical verification

Only recorded input audio was used. Operations: crop/downmix/resample, 35–45Hz high-pass and per-cue low-pass, fades, DC correction, real-recording layering, transient gain automation and loudness normalisation. No generated noise, oscillator, saturation or pitch shift. Several high-crest-factor sources needed repeated gain-envelope passes to reach the target without clipping; this can alter transients and requires listening for pumping/dulling. Short UI is 100–120ms.

Loudness uses the existing SOUND1 measurement convention: BS.1770 K-weighting/gating and short-clip zero-padding to 400ms. This is a consistent game-pack target measurement, not a claim about perceived loudness. General cues centre -24LUFS; UI near -32; bells/animals -27; Stitch -29; PotDrop -25; water -28 except dusk -30. Variants use up to 0.2LU offsets (Click 0.6LU lower).

Decoded checks PASS for all 71 files: correct format/channel count, target error under 1 LU, per-family spread under 2 LU, sample and estimated 4x true peak at or below -3dBFS, DC under 0.0007, faded one-shot endpoints. All five loops are exactly 1,323,000 stereo frames/30s with matched seam values/slopes within 1 PCM and nonzero live seam RMS. 100ms recorded-water overlap and 2ms endpoint correction were used; numerical continuity does not establish inaudible repetition.

Winch 8Hz/12Hz overlap at gain 0.65 peaks -7.56/ -6.21dBFS. This verifies that isolated overlap fixture only, not the native mixer with all other voices.

All 27 original waveform/spectrogram PNGs were opened and visually inspected. They show bounded waveforms, tapered one-shots, bell/animal spectral structure and continuous water beds. Later small water impacts are visible in Splash/NetSlap/PotDrop; listening must determine whether they fit each action. No audio playback/listening or native game test was performed.

Run from project root with ffmpeg available and the existing numpy/scipy/Pillow environment:

```sh
python3 -B Art/Source/Audio/acquire3.py
# Acquisition rechecks source pages; existing clean receipts are reused only if hashes match.
/home/mo/.venvs/catchline-ui/bin/python -B Art/Source/Audio/build3.py
/home/mo/.venvs/catchline-ui/bin/python -B Art/Source/Audio/check3.py
# Reopen changed sheets before renewing opened.json.
python3 -B Art/Source/Audio/document3.py
```

Acquisition accepts only direct approved OpenGameArt CC0 audio/zip. Each download is quarantined in a source folder and scanned with MpCmdRun before Python zipfile extraction or ffmpeg decode. Archives are inspected for forbidden executable extensions, traversal, absolute paths and symlinks; only audio/licence text is extracted. Sources/index.json retains all 25 clean receipts, scan commands, stdout and SHA256. Source-page HTML snapshots are documentary data and were not executed.
