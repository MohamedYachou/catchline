# HUD-V3-CUT-1 ? harbour

Source package for Claude review/import. No Assets or game code changed; no git actions.

## Files

- `manifest.json`: local PNGs and read-only reuse references, hashes, source rectangles, logical size and texture size.
- `layout.json`: every repeated use for phone 844?390 and desktop 1440?900. Coordinates are top-left device pixels.
- `text-styles.json`: live labels, unique ids per frame, rects, Fredoka Bold, size, colour and alignment. Sample words/numbers come from the concept; they do not propose current gameplay values.
- `slices.json`: stretchable entries. Border order is **left, bottom, right, top**, measured in texture pixels. Import PNGs at 3 pixels per logical phone pixel; divide borders by 3 when working in logical pixels. Fixed icons, portraits and pointed bubbles are aspect-fitted, not sliced.
- `phone/desktop-actual-size.jpg`, `phone/desktop-reconstructed-3x.png`, `phone/desktop-comparison.jpg`: review proofs. The left comparison is the supplied concept mapped to the frame; right is cut overlays and live labels. These are source reconstructions over the supplied scene, not runtime captures.
- `contact-actual-size.jpg`: each exported or reused piece at its phone placement size, no labels baked in.
- `package.py`: reproducible source-art packaging only. Run fishing first; harbour imports its packaging helpers. Requires Pillow, numpy and opencv-python-headless.

## Measurement and cleanup

The supplied concept is 1920?1080. `sourceRect` records the alpha-trimmed source cut, and `registrationRect` the original registration box. Placement maps x by target-width/1920 and y by target-height/1080. Thus the two requested frame sizes preserve the concept's composition with separate axis scaling; this is a measured proposal, pending Claude's responsive runtime integration.

Original rims, icons and portraits are foreground-matted from the concept. Text-bearing interiors are cleaned with a cream/orange/navy texture donor generated by the image tool and retained in `provenance/textless-tool-result.png`. Occluded symmetric backing caps are restored from their visible opposite cap. The fishing strike illustration also uses the textless tool cleanup. These reconstructed interiors are **not untouched pixel-exact source crops**. PNGs are 3x exports/upscales of the existing concept detail; they do not claim newly painted native 3x detail. The two source concepts are unchanged.

Reused accepted cuts are references in the manifest, never duplicate PNGs: fishing wallet and strike track; harbour refit track. Orange harbour buy buttons retain the concept's rounded silhouette after a rejected first reuse had the wrong shape.

## Checks and review limits

Independent `../hud-fishing/audit.py` passes: RGBA, tight alpha bounds, exact 3x dimensions, hashes/reuse targets, slice-cap limits, defined/in-frame placements, distinct text ids and 96 fitting phone/desktop labels across both packages. The preservation baseline checks 1,624 incumbent concept/exact PNG/manifest files unchanged. Final phone and desktop reconstructions and clean-piece contacts were visually opened during production.

The sample coloured bars are separate track/fill layers. Stretch to actual values at runtime. No hover/pressed states, gameplay additions, native imports or Unity captures were assigned. Native filtering, safe areas, runtime text metrics and Mo's visual approval remain outstanding. The cleaned meter backings and illustration are visible source substitutions; review the side-by-side before accepting the visual match.
