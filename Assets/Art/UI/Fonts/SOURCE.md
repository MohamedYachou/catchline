# Fredoka Medium

Source family: https://github.com/google/fonts/tree/main/ofl/fredoka
Original variable file: https://raw.githubusercontent.com/google/fonts/main/ofl/fredoka/Fredoka%5Bwdth,wght%5D.ttf
Licence: `OFL.txt` (SIL OFL 1.1). Copyright 2016 The Fredoka Project Authors.

Bundled `Fredoka-Medium.ttf` is a static instance at weight 500, width 100, produced with fontTools 4.67.0 `instantiateVariableFont`. The original naming, copyright and licence metadata are retained. One TTF supports both headings and live labels; no OS font dependency is needed in Unity. Font integration is deferred to the code pass.
